# Résumé — Anglais professionnel

## Email toolkit

| | Formal | Friendly |
|---|---|---|
| Start | *Dear Ms Taylor,* / *Dear Hiring Manager,* | *Hi Sam,* |
| Purpose | *I am writing to…* | *Just a quick note to…* |
| Ask | *Could you please…?* / *I would be grateful if…* | *Can you…?* |
| Attach | *Please find attached…* | *I've attached…* |
| End | *I look forward to hearing from you.* | *Thanks!* |
| Sign-off | *Kind regards,* / *Yours sincerely,* | *Best,* |

## Meetings

- Opinion: *In my opinion… / I think we should…*
- Disagree politely: *I see your point, but…*
- Clarify: *Could you clarify…?*
- Stand-up: *Yesterday I… · Today I'll… · I'm blocked by…*

## Presentations

*Today I'm going to talk about…* → *Let's move on to…* → *As you can see…* → *To sum up…* → *Any questions?*

Trends: *increase / rise* (hausse) · *decrease / drop* (baisse) · *remain stable* (stable) · *sharply* = a lot · *slightly* = a little.

## Interviews

> [!methode] STAR
> **Situation** → **Task** → **Action** (*I*, not *we*) → **Result**

"Tell me about yourself" = **present** (who I am) → **past** (what I've done) → **future** (what I want).

## Top mistakes

| Don't say | Say |
|---|---|
| *I have 22 years.* | *I'm 22.* |
| *I am agree.* | *I agree.* |
| *actually* (= actuellement) | *currently* |
| *since two years* | *for two years* |
| *informations, advices* | *information, advice* |
| *responsible of* | *responsible for* |
