## Plan du cours

1. **Chapitre I — Sockets** : introduction aux sockets, sockets en mode connecté (TCP), en mode paquet (UDP), API Java `java.net`
2. **Chapitre II — Architectures client/serveur** : problèmes d'intégration d'applications, fondements du client/serveur, RMI, API Java JNDI
3. **Chapitre III — Intergiciels orientés objets (CORBA)** : introduction aux intergiciels, architecture CORBA, composants et services, langage IDL et projection en Java
4. **Chapitre IV — Intergiciels orientés messages** : intergiciels orientés messages, API Java JMS, création et échange de messages, fiabilité

Chaque séance a son support (PDF) dans **Cours** et sa fiche détaillée dans **Résumés**.
